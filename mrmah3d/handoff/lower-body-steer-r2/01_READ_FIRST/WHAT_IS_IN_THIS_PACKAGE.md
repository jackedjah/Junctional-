# What is in this package

This package is meant to be uploaded to Claude alongside the existing MAH character project.

## Folder order

1. `01_READ_FIRST/`
   - Start here first.
   - Explains the purpose of the steer and what Claude should and should not do.

2. `02_PROMPTS/`
   - Ready-to-send prompt text.
   - `SEND_NOW.txt` is the immediate message.
   - `AFTER_KNEE_APPROVAL.txt` is only for the next step after you approve the current knee proof.

3. `03_MAIN_STEER/`
   - The full steering document.
   - This is the main instruction layer that explains the anatomy logic and guardrails.

4. `04_REFERENCES/`
   - `PRIMARY/` = the most important visual references.
   - `CONTEXT/` = supporting context only, not direct copying targets.
   - `ORIGINAL_USER_UPLOADS/` = the actual raw uploads that informed this steer.

5. `05_TECHNICAL/`
   - Three.js application notes and checks.

## Core rule

Upload the whole ZIP.
