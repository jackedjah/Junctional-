# Character Creator Flow

## Main flow

1. **Base / Identity** — choose starting MAHBEING presentation if applicable.
2. **Physique** — body archetype / proportions.
3. **Head / Face Frame** — canonical head/frame options if available.
4. **Eyes** — preset + advanced malleability controls.
5. **Face Details** — optional accents, lashes, cheek/face marks, etc.
6. **Hair** — existing/future diamond-hair system.
7. **Theme / Color** — character color/theme.
8. **Review** — rotate, expression test, confirm.

## Eye screen hierarchy

### Primary mode
- live preview
- category filter: Friendly / Personality / Shape / Special / All
- preset tiles
- selected preset name
- `Customize` entry
- `Save & Continue`

### Customize mode
Expose only useful controls. Recommended initial set:
- Width
- Open / Close
- Spacing
- Angle
- Iris Size
- Look X
- Look Y
- Detail intensity (if selected preset supports it)

Advanced controls should not overwhelm first-time users.

## Mobile behavior
- Preview occupies top/primary area.
- Preset browser uses 2–4 columns or horizontal cards depending viewport.
- Customize controls appear in a sheet/accordion below preview.
- Touch targets ~44px minimum.
- No poster-density UI on phone.

## Review behavior
Provide quick expression buttons:
Neutral / Happy / Focused / Curious / Surprised.
The user should immediately see that the same chosen eye can move and emote.
