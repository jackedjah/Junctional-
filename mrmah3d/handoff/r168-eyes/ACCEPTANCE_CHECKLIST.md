# R168 Acceptance Checklist

## Ownership / safety
- [ ] Existing character creator owner audited before edits.
- [ ] No duplicate appearance model introduced.
- [ ] No unrelated anatomy/world systems redesigned.

## Eye catalog
- [ ] At least a strong initial friendly/everyday selection exists.
- [ ] Round, almond, soft, kind, calm, warm, wide and neutral options exist.
- [ ] Focused/angular/special options exist without dominating the catalog.
- [ ] Pixel/faceted style is consistent.
- [ ] Cyan/ice-blue canonical preview palette is retained.
- [ ] Black MAHBEING face-display area remains intentional and visible.

## Malleability
- [ ] Width visibly adjusts live.
- [ ] Openness visibly adjusts live.
- [ ] Eyes can close/blink.
- [ ] Gaze moves left/right/up/down.
- [ ] Cant/angle can be adjusted if exposed.
- [ ] Iris size can be adjusted if exposed.
- [ ] Controls alter real runtime state, not a fake preview only.

## Signature identity
- [ ] Mr. Mah signature preset implemented.
- [ ] Mrs. Mah signature preset implemented.
- [ ] MAH Original signature preset implemented.
- [ ] Defaults remain recognizable at gameplay distance.

## Character creator
- [ ] EYES is a dedicated selectable step.
- [ ] Selected style is clearly highlighted.
- [ ] Live preview updates immediately.
- [ ] Back/forward preserves state.
- [ ] Save/reload preserves state.
- [ ] Legacy circle-eye saves migrate safely.
- [ ] Mobile layout is touch-friendly and not overcrowded.

## Expressions
- [ ] Neutral
- [ ] Happy
- [ ] Focused
- [ ] Curious
- [ ] Surprised
- [ ] Tired/relaxed
- [ ] At least one asymmetric/wink behavior if technically supported

## Performance
- [ ] Catalog does not instantiate dozens of heavyweight live character renderers.
- [ ] Eye animation does not create duplicate RAF loops.
- [ ] No obvious frame-time regression in creator or gameplay preview.
