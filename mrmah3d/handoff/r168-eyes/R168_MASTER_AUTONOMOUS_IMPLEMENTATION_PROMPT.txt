5. EYES ARE MALLEABLE — NOT STATIC ONLY
======================================================================

The eye preset is a STARTING FORM.
The runtime character appearance model must support independent parameters for at least:

- eye width
- eye height / openness
- horizontal spacing
- vertical placement
- lid angle / cant
- upper-lid position
- lower-lid position
- iris size
- iris/pupil X offset
- iris/pupil Y offset
- gaze direction
- blink amount
- blink speed/default cadence metadata
- expression openness multiplier
- optional lash/detail intensity where relevant

If the current renderer is 2D/SVG/canvas, implement these as transforms/paths/masks appropriate to the owner.
If the current renderer is Three.js, implement via geometry, morph targets, shader uniforms, UV transforms, sprite transforms, or another maintainable runtime method.

Do NOT fake malleability by storing sliders that do not affect the actual preview.
Every exposed control must visibly change the live face.

Required behaviors:
- widen / narrow
- open / close
- half-lid
- blink
- wink if supported
- look left/right/up/down
- neutral reset

======================================================================
6. BLACK FACE DISPLAY IS CANONICAL
======================================================================

The black area seen behind the eye references represents the MAHBEING face-display region.
Keep it.

Do not add a conventional skin-tone face plane behind the eyes.
Do not require a full white sclera for every style.

The eye system should use the black field as intentional negative space.
White/ice-blue eye pixels, cyan cores, and selective highlights should read strongly against it.

The face must remain recognizable at:
- full-body gameplay distance
- character creator medium distance
- face close-up

======================================================================

Create / preserve signature defaults for the progenitor/original characters.

MR. MAH SIGNATURE DEFAULT:
- immediately recognizable
- welcoming but focused
- not angry by default
- slightly more compact / intentional than the old circles
- pixel/faceted cyan/ice-blue construction
- black face-display field retained

MRS. MAH SIGNATURE DEFAULT:
- kind / confident / inviting
- may use tasteful lash/detail treatment
- not automatically hyper-feminine or doll/anime-coded

Both defaults must be implemented as normal presets + parameter values inside the same system.
Do NOT hard-code a separate face renderer exclusively for Mr. or Mrs. Mah.

Also create a "MAH Original" / signature-family preset that evokes the original simple-circle heritage without literally reverting to two unchanged circles.
It should feel like the EVOLUTION of the original face:
- friendly
- iconic
- extremely readable
- rounder/open geometry
- subtle pixel/faceted edge character
- restrained cyan core
